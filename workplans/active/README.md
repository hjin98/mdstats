# Active workplans

Active workplans are temporary engineering coordination and do not define current mdstats behavior by themselves.

There is one active MLFF implementation workplan:

- `MLFF_TARGET_SIZE_TRAINING_PRIORITY_EVALUATION_LADDER_ARCH_RESET_WORKPLAN.md` — V6 scientific simplification. Electronic-structure provenance is recorded precisely but is advisory by default; one target-size study operates across the user-authorized usable target data. Target-size selection is a controlled convergence experiment in training cardinality `N`, with one deterministic training order, one disjoint nested `M1/M2/M3` evaluation ladder, fixed non-`N` training choices, exact `n1/n2/n3` continuation, paired seeds, configured power ladders/ceiling, and nominal `Nmax + M3` capacity. Cross-validation is a separate post-selection methodological-validation experiment built only from frozen `T_selected`. The plan collapses retired per-domain and FEAS/MVIDX/MVSEL/REPAIR/MVQUAL target-size authority layers while allowing optimized numerical kernels to survive internally.

All earlier target-size architecture-reset revisions are superseded by V6. Full long real-data/GPU production qualification remains separate and deferred to final release. Scientific M-ladder qualification is reported separately and may be `deferred/unavailable` when representative evidence is unavailable.
