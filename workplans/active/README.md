# Active workplans

Active workplans are temporary engineering coordination contracts. They do not define current mdstats product behavior by repository presence alone; current behavior remains owned by accepted D1-D4 authority and conforming implementation.

## Current active MLFF work

`MLFF_POST_SELECTION_UNIVERSAL_LOSS_MONITOR_AND_CV_METHOD_RESTORATION_WORKPLAN.md` is active on `fix/mlff-post-selection-method-restoration`.

It records a **Serious Challenge to current foundation-adaptation P5 D1/D2 semantics** after severe replay forgetting and reconstruction of the historically successful path. Current D1 requires weighted energy+forces+stress execution and a checkpoint monitor drawn from fold training-eligible evidence; D2 concretizes those choices. The plan therefore requires **D1-first, then D2** adjudication before D3/D4 implementation.

The proposed restoration uses native MACE `UniversalLoss` with explicit `huber_delta=0.01` and global E:F:S `1:10:1`, removes non-executable P5 configuration weighting and target/replay training-head scalar weighting, restores one protected campaign-common 256-frame target checkpoint monitor over current neutral `OUTER_MONITOR`, and returns the default post-selection CV policy to three folds while preserving TRUE_DFT replay and current acceptance semantics.

Independent review additionally found a D4 conformance blocker that does **not** require weakening D1: current foundation-adaptation P5 can default to from-scratch total-energy E0 fitting even though accepted D1 requires checkpoint/head-bound foundation-residual E0 fitting. The workplan now requires exact fold/final residual-E0 wiring, selected-foundation-head E0/prediction qualification, explicit `force_mh_ft_lr=true` preservation, and retirement of current M3-as-final-checkpoint-monitor routing. M3 itself remains unchanged target-size model-selection evidence.

The plan also collapses the competing fold/final MLCV target-monitor path onto the one common target monitor, while preserving TRUE_DFT replay-monitor and training-diagnostic roles, and advances currentness so historical stress/fold-local/M3-monitor/from-scratch-E0 foundation state cannot resume as current.

Repository presence does not promote these proposed semantics. The accepted MLFF scientific/numerical method papers remain current until their challenged P5 clauses are formally amended and accepted.

There is no active target-order redesign. The withdrawn FPS/coverage Gate-A lineage remains archived and does not alter the accepted target-size method, including the deterministic exact protected-component subset-sum split and target-order behavior.

Completed/superseded workplans belong under `workplans/archive/`. Production-scale GPU/CuEq/LAMMPS/MLIAP qualification remains deferred to final release.
