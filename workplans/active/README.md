# Active workplans

Active workplans are temporary engineering coordination contracts. They do not define current mdstats product behavior by repository presence alone; current behavior remains owned by accepted D1-D4 authority and conforming implementation.

## Current active MLFF work

`MLFF_POST_SELECTION_UNIVERSAL_LOSS_MONITOR_AND_CV_METHOD_RESTORATION_WORKPLAN.md` is active on `fix/mlff-post-selection-method-restoration`. It records a **Serious Challenge to current P5 D1/D2 semantics** after severe replay forgetting and reconstruction of the historically successful foundation-fine-tuning path. The challenged accepted D1 clauses currently require weighted energy+forces+stress execution and a checkpoint monitor drawn from fold training-eligible evidence; accepted D2 concretizes those choices. The plan therefore requires **D1-first, then D2** adjudication before D3/D4 implementation.

The proposed restoration uses native MACE `UniversalLoss` with explicit `huber_delta=0.01` and global E:F:S `1:10:1`, removes non-executable P5 configuration weighting and target/replay training-head scalar weighting, restores one protected campaign-common 256-frame target checkpoint monitor over the current neutral `OUTER_MONITOR` authority, and returns the default post-selection CV policy to three folds while preserving TRUE_DFT replay and current target/replay acceptance semantics. The second review also requires collapsing the competing fold/final MLCV target-monitor path onto that common monitor, preserving replay-monitor/training-diagnostic roles, and cutting over run/currentness schemas so historical stress/fold-local state cannot resume as current.

Repository presence of the plan does not promote those proposed semantics to current authority. The accepted 2026-09-13 MLFF scientific and numerical method papers remain current until their challenged P5 clauses are formally amended and accepted.

There is no active target-order redesign. The withdrawn FPS/coverage Gate-A proposal lineage remains archived and does not alter the accepted target-size method. In particular, the accepted deterministic exact protected-component subset-sum split and target-order behavior remain unchanged.

Completed, superseded, and retired workplans belong under `workplans/archive/`. Production-scale GPU/CuEq/LAMMPS/MLIAP qualification remains deferred to the established final-release phase.
