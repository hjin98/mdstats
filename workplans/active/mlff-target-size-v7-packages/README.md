## Cross-package rules

- The frozen parent is the controlling scientific/architectural verdict; package amendments may reconcile implementation consequences but may not silently change it.
- Historical workplan/evidence records are preserved. Current authority files identify which revisions are operative.
- P3 owns scientific execution evidence/replay; P4 consumes/adopts that authority rather than recreating reducer/replay semantics.
- P4 owns the production runtime/persistence cutover and current selected-binding/currentness model.
- P5 consumes exact `T_selected`, performs complete selected-only CV under the frozen method/policy identities, and owns fresh final production.
- P5/P6 already provide the final-production publication/currentness/reopen path consumed by P7. P7 must not create an alternate publication/member-selection authority.
- P6 removes retired architecture only after current runtime closure and owns the accepted transitional storage public surface, current-cache owner, and safe-cleanup owner.
- P7 is read-only with respect to target-size selection, CV, production training, representative-checkpoint/seed/member choice, and publication membership.
- P7 downstream deployment/physical/calibration/locked evidence has pass/reject/waiting authority only for the exact frozen product; it has zero fallback/model-selection authority.
- P7 qualification evidence binds the exact P7 executable commit/tree, exact frozen publication and artifacts, qualification spec/policy, target-machine environment/runtime identities, protected/reference evidence, and terminal results.
- P6 bounded proxy/device/resource evidence is development evidence only. It cannot satisfy P7's final target-machine/release qualification gate.
- P7 may add owner-local immutable qualification evidence, resumable attempt state, and a minimal active-artifact retention reference. It must not create a second cache/cleanup authority or implement the successor storage inventory/archive/dedup/admission plane.
- Explicit one-shot locked-test activation remains mandatory and never automatic.
- Full production qualification is distinct from regression/integration: regression establishes functionality and absence of hard failures; final target-machine qualification establishes real deployment/physical/resource claims for the frozen release candidate.
