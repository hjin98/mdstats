# Render Tuning Audit

- 3-D default camera projection changed to orthographic.
- 3-D equal-aspect scenes now use an explicit manual aspect ratio derived from display extents.
- Default unit-cell wireframe width increased to 3.2 and alpha to 0.72.
- Atomic graph default edge widths and node outlines were increased for readability in both 2-D and 3-D.
