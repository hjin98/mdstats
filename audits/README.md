# Audits

This directory contains validation evidence. Every file uses the `_audit.md` suffix.

- `analysis/`: analysis-module, neighbor-search, and scientific-equivalence audits.
- `plotting/`: graph-rendering and visualization audits.
- `release/`: complete-suite and release-readiness audits.

Performance measurements are not audits; they are stored under `benchmarks/` with the `_benchmark` suffix. Release manifests and checksums are stored under `release/`.
