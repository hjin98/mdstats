# PeriodicNetView Implementation Audit

Date: 2026-07-18  
Version: `0.19.14a0`  
Architecture: revision 21

## Scope

This gate implements the first signature-only `PeriodicNetView` backend. It does
not discover symmetry, alter the source graph, reduce the source lattice, or
construct an embedding.

## Implemented contracts

- immutable `NetViewPolicy` with deterministic enum-based signature fields;
- unlabeled-framework and chemically decorated built-in policies;
- exact preservation of source framework vertices, edges, shifts, and parallel
  multiplicity;
- source graph/topology, policy, and view digests;
- exact source lookups and source-validated serialization;
- quotient components and deterministic fundamental cycle-gain generators;
- exact periodic translation rank;
- finite full-rank subgroup index from greatest common divisors of maximal integer
  minors; and
- `natural_tiling_eligible` requiring 3D PBC, one quotient component, rank three,
  and index one.

## New issue resolved during implementation

A connected finite quotient with rank-three cycle gains need not define one
connected infinite lift. A subgroup generated by `(2,0,0)`, `(0,1,0)`, and
`(0,0,1)` has rank three but index two in `Z^3`, producing two translation cosets.
The implementation therefore records `translation_index` and rejects index-greater-
than-one views from the first natural-tiling backend.

## Scientific invariants

- `V_view = V_framework` and `E_view = E_framework` exactly.
- Equal signatures permit exchange but never merge source records.
- Primitive-ring identity remains source graph digest plus `PrimitiveRingKey`.
- The net-view digest is additional symmetry/tiling provenance.
- Descriptive policy labels do not alter semantic policy/view digests.
- Structural filtering or contraction remains out of scope.

## Algorithmic provenance

Periodic quotient-edge gains follow Chung, Hahn, and Klee (1984) and Klee (2004).
The exact policy-bound periodic-net viewpoint follows Delgado-Friedrichs and
O'Keeffe (2003). The full-rank subgroup index uses the determinant-divisor/Smith-
normal-form result described by Newman (1972). These references appear in the
module specification and implementation comments.
