# mdstats 0.20.201a0 patch notes

This release implements **TARGET-DATA2C-MVIDX1** (architecture revision 68 / graph schema 50). It builds exact bidirectional sparse candidate/witness coverage adjacency for every required TARGET-DATA2B family plus first-class extent, stratum, and correlation-interval obligation indices. Scientific arrays are content-addressed NPY sidecars with checksum-protected manifests. The record is integrated into `prepare` as `target_coverage_sparse_index`.

The release is still pre-migration: TARGET-DATA2C v4 selection and revision-64 rescue remain unchanged. The next implementation gate is TARGET-DATA2C-MVSEL1.
