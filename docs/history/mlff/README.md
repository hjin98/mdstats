# MLFF documentation history

This tree records **non-normative lineage**. Current scientific and execution contracts live in `docs/arch_manuals/mlff_training_data_architecture.md` and `docs/specs/training_data/`.

- `LINEAGE.md`: era-level map of code-development history and index ownership.
- `architecture_revisions/`: one note per architecture revision; see its `INDEX.md`.
- `release_notes/`: release and hotfix deltas; see its `INDEX.md`.
- `manual_snapshots/`: selected full historical manual/render snapshots retained for provenance.
- `legacy_rendered_artifacts/`: rendered historical artifacts that lack a canonical current source role.
- `legacy_root_documents/`: retired parent-level reports retained for lineage rather than discarded.

New revisions must update the current manual first, then add a concise lineage note here. Do not prepend revision commentary to the canonical architecture manual.
