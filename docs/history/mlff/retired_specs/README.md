# Retired MLFF specifications

These specifications documented the pre-V7 target-size generation: the
compatibility-domain role freeze, full-pool feasibility, the exact sparse
neighborhood index, the multi-view selector/repair/continuation/qualification
chain, the fixed target-size study, the per-domain production materialization,
and the retired `materialize`/`preflight`/`train`/`extend-seed`/`evaluate`/
`verify` execution lifecycle together with its MLCV and adaptive-stop families.

The destructive target-size generation cutover removed those owners from the
current runtime and public API. Nothing here is current authority. The documents
are retained only so durable historical evidence produced under that generation
remains interpretable.

Current behavior is defined by `docs/arch_manuals/mlff_training_data/` and the
specifications that remain under `docs/specs/training_data/`.
