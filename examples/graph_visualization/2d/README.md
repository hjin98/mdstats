# Na-LTA graph-visualization integration gallery

These figures were generated by `render_na_lta_2d.py` from
`tests/data/Na_LTA_relaxed.POSCAR`.

## Authoritative framework graph

The framework graph contains the first 144 Si/Al/O atoms. Edges use strict
cutoffs `Si-O < 2.0 A` and `Al-O < 2.0 A`.

Verified structure:

- 144 framework atoms;
- 192 T-O edges;
- degree 4 for every Si/Al atom;
- degree 2 for every framework oxygen atom.

Recommended diagnostic images:

- `na_lta_framework_orthographic_contact.png`: XY, XZ, and YZ views side by side;
- `na_lta_framework_physical_pca.png`: one full PCA projection;
- `na_lta_framework_local_si0.png`: focused three-hop neighborhood;
- `na_lta_framework_local_si0_hop4.png`: focused four-hop neighborhood;
- `na_lta_framework_spring.png`: schematic topology-only layout.

Pale endpoint points are display-only periodic ghost images. They are not extra
atoms and do not enter graph identity or node counts.

## Broader Na-O diagnostic

`na_lta_full_atomic_physical_pca.png` includes all 168 atoms and adds Na-O
contacts using an illustrative `Na-O < 3.15 A` cutoff. The resulting display graph
has 302 edges. This value is a visualization fixture, not a universal chemical
bond definition.

## Reproduction

From the source-tree root:

```bash
PYTHONPATH=. PYTHONWARNINGS=ignore python examples/graph_visualization/2d/render_na_lta_2d.py
```
